# Docs

Pages for people: new users, teammates and anyone you show the workflow to. Claude does not read these; its rules live in the skills and `memory/`.

| Page | For |
|---|---|
| [Getting started](getting-started.html) | Setup once per computer, your first session, and working as a team (Solo or Team, joining, adding a teammate) |
| [Workflow map](workflow-map.html) | Every stage and question, from Setup to Storybook, as an interactive map |
| [FAQ and troubleshooting](faq.html) | Recurring problems with FigCli, the Desktop Bridge, setup, team projects and Storybook, with fixes |
| [Presentation](presentation/AI-Ready-Design-Systems.html) | The slide deck that introduces the workflow |

**Open them:** GitHub shows HTML files as code, so download or clone the repo and double-click a page to open it in your browser. All pages share `assets/docs.css` and follow your system's light or dark mode.

**Keep them current:** a pull request that changes the intake, setup or team steps updates the matching page in the same pull request. A fix logged in `memory/lessons.md` that users can hit again gets a FAQ entry.
