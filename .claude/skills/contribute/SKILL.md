Read and follow `CONTRIBUTING.md` in the repo root (the folder that contains `.claude/`). That file is the source of truth; this entry only makes it available as `/contribute`.

- No argument, or a description of what to share: section 2 (Steps). Prefill everything the session already knows.
- `review`: section 3 (Review), only for the repo owner.

Nothing is sent before the "Send it for review" answer, work happens on a `contrib/` branch (never `master`), and nothing reaches `master` before Abdul accepts it.
