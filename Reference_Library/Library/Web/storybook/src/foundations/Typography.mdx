# Typography
Figma page `➜ Typography`. Font: Poppins (`Typography::Font Family/Font Family`). 40 text styles named `{size}/{weight}`, each bound to the Typography variables, which change per mode (Desktop / iPad / Mobile). Switch **Mode** in the toolbar to see the responsive scale. CSS class = style name with `/` and spaces as `-` (`sm/Semi Bold` → `.ts-sm-semi-bold`).
