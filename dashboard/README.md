# Dashboard

A local browser interface for the workflow. It is a window onto Claude Code, not a second workflow: every conversation runs Claude Code in the Root with your own settings, sign-in, skills, hooks and memory files, exactly as in the terminal.

## Start
- Windows: double-click `Start-Dashboard.cmd` in the Root. Mac: `Start-Dashboard.command`.
- The first start runs `npm ci` here (one package, `@anthropic-ai/claude-agent-sdk`), then opens http://localhost:4777. Keep the window open while you work; closing it stops the dashboard and any running conversation.
- Needs Node.js 18+ (`Setup-Windows.cmd` / `Setup-Mac.command`) and Claude Code installed and signed in on this computer (open `claude` once in a terminal to sign in).
- By hand: `npm ci` in this folder, then `node server.mjs --open`. Other port: `DASHBOARD_PORT=4800`.

## What it shows
| Screen | What you do there |
|---|---|
| Dashboard | Start a new project (the intake), join a team project, a quick task (`/ds-quick`) or any request; totals (projects, Storybook changes waiting, running conversations, Figma); continue a recent conversation (named by the first thing you typed, with its project as a tag; search and Show all reach the last 40; the x removes one from the list with Undo, Claude keeps it); **Worth a look** tips at the bottom |
| Projects | Every folder in `My Projects/` as **Cards** or a **Table** (the choice is remembered): stage, last CHANGELOG entry, next step, Storybook changes waiting, links. **Add project** copies `_Project_Template/` into a new folder (optionally starting the intake in it); **Edit** renames the display name only (the folder keeps its name); **Delete** asks you to type `Delete`, moves the folder to `.claude/.state/trash/` and shows a toast with **Undo** for 30 seconds, then removes it for good. A project with a running conversation cannot be deleted |
| Conversation | Claude's replies; tool steps as small chips; AskUserQuestion menus as buttons (recommended first, Back, an "Other" box, several questions with "Send answers"); permission prompts as Yes / Yes, don't ask again / No; screenshots Claude takes or reads moved into the next approval card (click to zoom); paste, drop or attach your own images; Stop; Open in Claude Code (`claude --resume` in a terminal). The left menu hides while you work in a project (All projects goes back). **Model** picker under the message box switches Claude's model inside the same conversation and is remembered for the next one. Reading: a **Latest** button (with the count of new messages) when you scroll up, a date line after a 30-minute gap, the time on hover, Copy on every reply and code block, long rows of tool steps folded to the newest 5. Unsent text is kept per conversation, and the browser tab title says *Waiting for your answer* or *Done* while you are in another tab |
| Style library | Every style in `Style_Library/styles.json` as a card with its first colors, category, one-line description and an **Inspired by a brand** tag; filter by category and search (kept for the browser tab). **Read** shows its `DESIGN.md`; **Use for a new project** starts the intake with that style preselected for 0.3e (look only: the components keep the reference structure). Under **Add to the workflow**, **Style** adds a new one through `/contribute` |
| Add Inputs | In a project: a popup with Brand, Inspiration, Screens and Research tabs, each a drop zone with Browse (50 MB a file). Files are copied to the project's `Inputs/<tab>/`, listed with Remove, and **Ask Claude to read them** sends their paths to the conversation |
| Usage limit | When Claude hits its limit the conversation stays open: a card shows when Claude is back, messages you send meanwhile wait and go out then, and (on by default) the same conversation continues by itself a minute after the reset, first reading any CHANGELOG or handoff work another tool did meanwhile. **Try now**, or **Continue with Gemini here** (the same conversation goes on with Gemini; Claude waits until you switch back) |
| Project sidebar | Quick actions that send a prompt: Continue, Run an audit, Add or change a component, Change a token, Update Storybook, Project status |
| Sign in | The pill at the top right shows whether Claude Code is signed in (`claude auth status`). **Sign in** runs `claude auth login`: the browser opens the Claude sign-in page, a code box appears if the page gives a code, and the pill turns green when done. An expired sign-in inside a conversation shows a card with Sign in and Try again. Fallback: Use a terminal instead (`claude`, then `/login`) |
| Add to the workflow | Reference design system, Icon library, Skill from GitHub. The dialog lists what you need and what happens, asks for the name and link (Figma or GitHub links are checked), then starts `/contribute` with them (CONTRIBUTING.md: the work happens on a branch and ends as a pull request after "Send it for review") |
| Permissions pill | How often Claude asks, saved in `.claude/.state/dashboard-settings.json` and applied at once to running conversations: **Auto** (Recommended, Claude Code's auto mode: routine steps run, risky ones still ask) or **Ask every time**. A mode that never asks is not offered. AskUserQuestion menus and checkpoints are decisions, not permissions, so they always wait for you |
| Settings | **AI tools**: Claude Code, Codex, Gemini CLI, Cursor CLI, Copilot CLI and the Antigravity app, each with installed / version / signed-in state, **Sign in** (opens the tool's own login command in a terminal), **Open** and a model field (empty = the tool's default). **When Claude hits its usage limit**: Ask me / Codex / Gemini. **Usage**: tokens and turns per tool, today and 7 days, top projects, last limit (`.claude/.state/dashboard-usage.json`, this computer only). **GitHub** account and repo with Sign in (`gh auth login --web`), **Figma** tools check, permissions and Node / Python / Git versions. No token or password is read, stored or shown |
| Another tool | The **Tool** picker under the message box switches who answers in the same conversation: **Claude** or **Gemini CLI**. Gemini runs inside the window (`gemini --acp`, the Agent Client Protocol): its replies appear in the conversation marked Gemini CLI, its edits and commands ask first as the same Yes / Yes, don't ask again / No cards, and the model picker lists Gemini's models. On the first switch Gemini reads `AGENTS.md` and the conversation so far (`.claude/.state/handoff.md`); when you switch back, Claude gets Gemini's part and audits its work before answering. Codex and Antigravity still open in their own window with the handoff note (**Continue with another tool**) and ask their own approvals there |
| Update banner | Appears when `origin/master` has merged changes you do not have, listing them. **Update now** runs `git pull --ff-only origin master` in the Root: it never merges, discards or overwrites local edits, and stops with the file names when it cannot fast-forward |

## How it works
- `server.mjs` (Node, no framework) listens on 127.0.0.1 only and refuses requests from other sites.
- Each conversation is one `query()` from the Claude Agent SDK with `cwd` = Root and `settingSources` user, project and local, so `CLAUDE.md`, `.claude/settings.json` hooks, skills, agents and your permission mode load as in the terminal. The installed `claude` is used when found (a Windows `.cmd` shim falls back to the SDK's own copy).
- `canUseTool` turns every AskUserQuestion call and permission prompt into an event for the browser and waits for the click; answers go back as the tool's `answers` (question text -> label, several labels joined with ", ").
- Events reach the browser over Server-Sent Events; a reload replays the conversation. Recent conversations (the last 40) are saved in `.claude/.state/dashboard-sessions.json` and what each window showed in `.claude/.state/dashboard-logs/<Claude session id>.json` (both git-ignored, the 60 newest screenshots kept). **Continue** resumes the same Claude Code session and shows the earlier messages again above a note, so you can scroll back after the dashboard or the computer was restarted; old questions, permission prompts and limit cards that were never answered are left out.
- `public/` is plain HTML, CSS and JavaScript (no build step) with its own stylesheet (the print-production look, light and dark) and inline Lucide icons. Fonts (Archivo, Red Hat Mono; OFL in `public/fonts/OFL.txt`) are served from `public/fonts/`, so the dashboard needs no internet.
- `tools.mjs` detects the other AI tools, holds their login and handoff commands and keeps the usage log. `acp.mjs` is a small Agent Client Protocol client that runs Gemini CLI inside a conversation. The dashboard never runs another tool unattended: Gemini asks before every edit or command through the dashboard's cards, and the others open in their own window.

## Rules for changing it
- Workflow logic stays in the skills. The dashboard only starts conversations with a prompt; it never re-implements intake questions or checkpoints, so a skill change needs no dashboard change.
- Hidden projects: list folder names in `private/dashboard-hidden.txt` (git-ignored, one per line); they never appear.
- Nothing here sends data anywhere except what Claude Code itself sends.
