# Gemini instructions

Read `AGENTS.md` first. This repo has a live Storybook of the Figma design system at `Trianglz/storybook/`: at the start of a session, mention it in one line (information only); ask about the project first and about Storybook only at intake 0.7, for a project with pending Storybook work, or when the user asks Run it with `npm install` then `npm run storybook` in that folder (Node.js 18+, ask before installing); it serves http://localhost:6006 and a Storybook MCP at http://localhost:6006/mcp.

Building screens (Antigravity and Gemini): follow `AGENTS.md` handoff item 7 (screen fidelity) and item 8 (never approve a checkpoint yourself). Open every source screenshot before building, write the screen spec, fill every instance with the real content, build one section per script, and compare each screen side by side with its source before reporting.
